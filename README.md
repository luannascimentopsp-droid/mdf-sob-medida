# Cardoso Projetar — MDF sob medida

Website estático de apresentação da Cardoso Projetar, marcenaria planejada em MDF.

## Recursos

- Apresentação de serviços, projetos e etapas de atendimento.
- Formulário para solicitar orçamento, com encaminhamento dos dados preenchidos ao WhatsApp da empresa.
- Layout responsivo para celular e computador.
- Painel demonstrativo com dados fictícios; não oferece autenticação nem armazenamento de pedidos.

## Publicação

O site não exige dependências ou etapa de compilação. Publique `index.html` em qualquer hospedagem estática. Para GitHub Pages, configure a branch principal e a pasta raiz como origem de publicação.
